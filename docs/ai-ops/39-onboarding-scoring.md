# 首登問卷推薦計分規則

抓取／定案日：2026-07-31

## 用途與邊界

此問卷只為「尚未開啟任何技能」的新店推薦一個技能套餐。它不改價格、不計算金額、不自動開啟高風險功能，也不新增後端資料欄位。

推薦結果固定包含：

1. 新手套餐（基礎）
2. 最多一個主要套餐

只有按下「套用推薦」後，前端才會呼叫既有套餐套用 API。

## 四題與計分

每個選項只加 0、1 或 2 分；未回答不加分。

| 題目             | 選項               | 加分               |
| ---------------- | ------------------ | ------------------ |
| 最想先處理的工作 | 基本流程           | 新手 +2            |
|                  | 成本毛利           | 成本 +2            |
|                  | 團購訂單           | 團購 +2            |
|                  | 客戶分級           | 批發 +2            |
|                  | 出貨物流           | 物流 +2            |
|                  | 減少重複操作       | 自動化 +2          |
| 成本管理需要     | 暫時不用           | 新手 +1            |
|                  | 大概毛利           | 成本 +1            |
|                  | 精確分攤與定格     | 成本 +2            |
| 訂單量           | 少量               | 新手 +2            |
|                  | 中量               | 團購 +2、物流 +1   |
|                  | 大量               | 批發 +2、自動化 +1 |
| 物流需求         | 手動即可           | 新手 +1            |
|                  | 經常出貨           | 物流 +2            |
|                  | 減少查件與更新時間 | 自動化 +2、物流 +1 |

## 勝出與同分規則

最高分為主要套餐；同分時固定依下列順序選一個：

`新手 → 成本 → 物流 → 團購 → 批發 → 自動化`

因此結果永遠可重現，不會因物件排序或執行環境不同而改變。若全部跳過或所有答案無效，結果只有新手套餐。
