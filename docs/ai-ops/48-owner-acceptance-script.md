# 老闆驗收腳本

- 更新日：2026-07-31
- 全程只用假店鋪、假客戶與假訂單；不要填真實客人資料。
- 每完成一段，就把畫面結果或錯誤文字記下來。不要為了過關把「待確認」當成 0。

## 1. 購物金：發放、折抵、取消回沖

1. 到「設定 → 客戶管理」，建立一位假客戶，再點客戶卡右側「詳情」。
   - 成功：看得到「購物金餘額」與「最近流水」。
   - 不對時回報：目前網址、畫面標題，以及是否看到 404 或「尚未開啟」。
2. 在「發放／調整」選「發放（正數）」，輸入 `5000` 與原因，按「預覽並確認」。
   - 成功：預覽顯示變動前餘額與變動後 `NT$5,000`。
   - 不對時回報：輸入值、預覽前後金額與畫面錯誤文字。
3. 按「確認變更」。
   - 成功：餘額變成 `NT$5,000`，最近流水新增一筆發放。
   - 不對時回報：按鈕是否可按、餘額是否更新、流水是否新增。
4. 到「訂單」，新增一筆綁定這位假客戶的假訂單，在「購物金折抵」填 `220` 後建立。
   - 成功：訂單顯示購物金折抵 `-NT$220`，應付現金比原金額少 220；客戶流水新增「訂單折抵」。
   - 不對時回報：原訂單金額、折抵、應付現金與客戶餘額。
5. 在該訂單選「取消訂單」，再按「確認取消」。
   - 成功：客戶餘額回到 `NT$5,000`，最近流水新增「取消回沖」，不需要人工再補一筆。
   - 不對時回報：取消前後餘額、是否看到回沖，以及訂單狀態。

## 2. 賣貨便：檢查兩區並下載 CSV

1. 到「訂單」，打開「賣貨便匯出」。
   - 成功：看得到開始日期、結束日期與「檢查可匯出訂單」。
   - 不對時回報：入口是否存在，以及畫面是否顯示技能尚未開啟。
2. 日期選到涵蓋示範訂單的範圍，按「檢查可匯出訂單」。
   - 成功：同時看到「可匯出」與「不可匯出」兩區；示範庫應各有 3 筆，不可匯出區會寫明原因。
   - 不對時回報：日期、兩區筆數與每一條錯誤原因。
3. 在「可匯出」勾選訂單，按「準備匯出 N 筆」。
   - 成功：出現「將匯出 N 筆明文個資」提醒，下載鈕此時仍不能按。
   - 不對時回報：勾選筆數、提醒文字與按鈕狀態。
4. 勾選「我確認本檔僅用於賣貨便出貨」，按「確認並下載 CSV」。
   - 成功：下載 CSV，畫面顯示已下載筆數。
   - 不對時回報：檔名、下載筆數與錯誤文字。
5. 用試算表開啟檔案，確認第一列有 10 個賣貨便欄名、資料列沒有跑欄；驗收後立刻刪除檔案。
   - 成功：姓名、手機、門市、溫層、商品、訂單金額與運費都在正確欄位。
   - 不對時回報：哪一列、哪一欄錯位；不要轉傳含明文資料的檔案。

## 3. 首登問卷：推薦並套用套餐

1. 使用一個尚未開啟任何技能的新假店鋪登入首頁。
   - 成功：看到「用 4 題找到適合的技能套餐」。
   - 不對時回報：店鋪是否已有技能，以及首頁實際出現的卡片名稱。
2. 回答 4 題後按「查看推薦」。
   - 成功：看到「你的推薦套餐」，並分開列出可立即開啟、需確認與缺前置的項目。
   - 不對時回報：四題選項與推薦結果；不要自行改技能前置資料。
3. 按「套用推薦」。
   - 成功：看到「推薦套餐已套用」；低風險項目已開，高風險項目仍需到技能地圖確認。
   - 不對時回報：按鈕是否可按、錯誤文字與沒有開啟的技能名稱。
4. 另一個新假店鋪可按「跳過問卷，使用新手套餐」。
   - 成功：仍先看到推薦內容，按「套用推薦」後套用新手套餐。
   - 不對時回報：跳過後顯示的套餐名稱與實際開啟項目。
